# Боевая Арена — мод для Minecraft 1.20.4 (Fabric)

Командные бои 3 на 3 прямо в меню Minecraft. Все бойцы, карты, эффекты и звуки — собственные
(рисуются кодом, звуки стандартные из Minecraft), ничего из Brawl Stars не используется.

## Как играть
1. Нажмите **B** (можно поменять в Настройки → Управление → Боевая Арена).
2. Выберите бойца, нажмите **ИГРАТЬ** — бой с ботами. Или создайте комнату и позовите друзей.
3. Друзья: вкладка «Комната» → ник → «Пригласить» (или дайте им ID комнаты, они вводят его сверху).
4. В бою здоровье постепенно восстанавливается, если вы не атакуете и не получаете урон в течение 3 секунд.
5. В комнате игроки могут переключать сторону кнопкой «Команда 1/2». Отключите ботов для дуэли с другом или распределитесь по командам и включите ботов, чтобы заполнить составы до 3 на 3.
6. Управление в бою: **WASD** — движение, **мышь** — прицел, **ЛКМ** — атака (зажать),
   **E** или **Q** — супер, **Пробел** или **Shift** — рывок. Кнопки справа внизу тоже кликаются.
   Персонаж Minecraft при этом стоит на месте и неуязвим. Esc — свернуть экран, B — вернуться.

Мод должен стоять и у всех игроков, и на сервере (для одиночной игры/«Открыть для сети» — просто в папке mods).
Нужен также Fabric API.

## Как собрать через GitHub (без установки Java)
1. На github.com: **+ → New repository**, имя например `boevaya-arena`, Public, **Create repository**.
2. На странице репозитория: **uploading an existing file**.
3. Распакуйте архив с проектом и перетащите **содержимое папки** (папки `src`, `.github`, файлы `build.gradle`,
   `settings.gradle`, `gradle.properties`, `.gitignore`, `README.md`) в окно браузера. Нажмите **Commit changes**.
   - Если папку `.github` перетащить не получилось (скрытая): **Add file → Create new file**, в имени напишите
     `.github/workflows/build.yml` и вставьте туда содержимое файла build.yml из архива.
4. Откройте вкладку **Actions**. Сборка идёт 3–6 минут. Зелёная галочка — готово.
7. Откройте последний запуск → внизу **Artifacts → boevaya-arena-mod** → скачайте, распакуйте, внутри `boevaya-arena-1.0.0.jar`.
8. Положите jar и Fabric API (1.20.4) в папку `mods`. Версия игры — Fabric 1.20.4.

Красный крестик — откройте запуск, скопируйте текст ошибки из шага «Собрать мод» и пришлите его.
